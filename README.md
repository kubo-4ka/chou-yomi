# 調よみ練習帳

楽譜の調号から「この曲は何調か」を読み取れるようになるための練習用の静的 Web アプリです。
音符が読めるようになって、いざ曲を弾こうと楽譜を開いた人や、自作ゲームに曲を付けようとしている人を想定しています。
HTML / CSS / JavaScript だけで動きます（ビルド不要）。

# DEMO

https://kubo-4ka.github.io/chou-yomi/

## 機能

画面下のメニューで 6 つの画面を切り替えます。

- **クイズ**（5／10／15／20／30 問）
  - 調号を読む：調号を見て、その調号を使う長調と短調の組（ニ長調／ロ短調 など）を答える
  - 手がかりで調を特定：調号に加えて手がかりが示され、4 つの調から答える。手がかりは「響きの明暗」「終わりの音」「導音の臨時記号」「メロディーの断片（再生可）」から選べる
  - 調号を選ぶ：調の名前を見て、その調号の五線譜を 4 つから選ぶ
  - 聴いて調を当てる：音階（構成音）→ 終止形の和音、音階だけ、和音だけ、短いメロディーのいずれかが流れ、調を答える。調号のヒント表示・基準のド（C4）の再生を切り替え可
  - 長調？短調？：流れたメロディー・和音・音階が長調か短調かを聴き分ける
  - 関係調：平行調・同主調・属調・下属調を答える（聞く関係を選べる）
  - 答えたあとに理由（「最後の ♯ ド ♯ のすぐ上のレ → ニ長調」など）を表示。「この調を詳しく」で調の詳細を開ける
  - ステップ：調号を読む → 調号を選ぶ → 平行調 → 明暗 → 終わりの音 → 導音 → 長調？短調？ → 楽譜の断片 → … → 総まとめ の 13 段階。押すと設定が切り替わってすぐ始まる
  - 記号（ト音・ヘ音・両方）、調号の数（♯・♭ 1〜7 つまで）、長調だけ／短調だけ、間違えた調を多めに出す、自動で次へ
  - 調の名前の表記：日本式（ハ長調）／英語（C major）／ドイツ式（C-Dur・a-Moll）／ドレミ（ド長調）
  - キーボード操作：1〜4 で回答、Enter で次へ、Space でもう一度聴く、Esc でやめる
- **調の一覧**：調号ごとに長調・短調（平行調）を 1 組にして 30 の調を表示。調を押すと詳細シート
  - 調号・見つけ方、音階（短調は自然・和声的・旋律的の 3 種）、主要三和音（I・IV・V）、終止形の再生
  - 平行調・同主調・属調・下属調へのリンク（調号が 7 つを超える場合は異名同音の調）
  - よく言われるイメージ、ゲームに曲を付けるときの使いどころ、楽器・演奏から見た特徴
  - この調で曲を聴いてみる：ハッピーバースデー／きらきら星／歓喜の歌／エリーゼのために（冒頭）を、その調に移した楽譜（拍子・付点・連桁・休符つき）で表示して再生。伴奏の和音つき、再生中の音を色付け。長調の曲を短調の調で開くと、同じ度数のまま短調に置きかえて鳴らす（逆も同じ）
  - その調の有名な曲（作曲者の没後、長い年月がたった曲）と、IMSLP のその曲（または曲集）のページへのリンク
  - 調号から調を見つける早見表
- **聴く**：曲（ハッピーバースデー／きらきら星／歓喜の歌／エリーゼのために）を選んで、いろいろな調に移して聴きくらべる画面
  - 1 つの調で聴く：プルダウンで調を選ぶほか、「半音上・下」「同主調（長調 ⇔ 短調）」「平行調」「属調・下属調」「原曲の調」のボタンでワンタップ移調。再生中に押すと新しい調で鳴らし直す
  - 選んだ調を順に聴く：チェックした調を、チェックした順に続けて再生（↑↓ で並べかえ、くり返し再生、調の切りかえの間合いを選べる）。再生中の調の楽譜に自動で切りかわる。「暗い → 明るい（同主調）」「半音ずつ上げて盛り上げる」「五度圏をめぐる」などのおすすめの並びつき
  - 記号（ト音・ヘ音）、音色、速さ、伴奏の和音のオン・オフ
- **五度圏**：外側が長調、内側が短調の円。押すとその調の調号と、平行調・属調・下属調・同主調を色分けして表示
- **学ぶ**：調とは何か、長調と短調、調号の読み方、調号から調を見つける方法、長調か短調かの見分け方、短音階の 3 種類、関係する調、転調、調のイメージは本当にあるのか、ゲームに曲を付ける人へ（場面別の例・響きを変える小技・旋法の聴きくらべ・パブリックドメインの曲を使うときの注意）、アプリの使い方。譜例はタップで音が鳴る
- **記録**：連続練習日数、今日・累計の問題数と正答率、2 週間の棒グラフ、苦手な調（そこから練習を開始できる）、調ごとの正答率
- 音色：ピアノ／純音／オルガン／シンセ／ストリングス／オルゴール（Web Audio API で合成、音声ファイル不要）
- ホーム画面に追加してアプリとして使える（PWA）。オフラインで動くのは https:// か localhost で配信した場合のみ
- ライト／ダークテーマ（初回は OS の設定に従う）

## ファイル構成

| ファイル                                    | 内容                                                                                          |
| ------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `index.html`                                | 画面（「学ぶ」の本文もここ）                                                                  |
| `style.css`                                 | デザイン（色は `:root` のトークンで管理。長調は暖色 `--major`、短調は寒色 `--minor`）         |
| `music.js`                                  | 音・調の理論（調号・音階・三和音・関係調）、調号つき五線譜の SVG 描画、音源（`window.Music`） |
| `keys.js`                                   | 調ごとのイメージ・ゲームでの使いどころ・有名な曲（`window.KEY_INFO`）                         |
| `melodies.js`                               | 「この調で曲を聴いてみる」の曲データ（度数・リズム・伴奏。`window.MELODIES`）                 |
| `app.js`                                    | アプリ本体（クイズ・一覧・五度圏・学ぶ・記録）                                                |
| `manifest.webmanifest` / `sw.js` / `icons/` | アプリとしてインストールするための設定・オフライン用キャッシュ・アイコン                      |
| `tools/serve.js`                            | ローカル確認用サーバ（`node tools/serve.js` → http://localhost:26838）                        |
| `tools/make-cert.js`                        | スマホから HTTPS で確認するための自己署名証明書を作るスクリプト（要 openssl）                 |

### 調の扱い

- 調号 `sig`（♯ は正、♭ は負、-7〜+7）と長調・短調の組で 30 の調を作っています。長調の主音は五度圏の位置 `sig`、短調は `sig + 3`
- 平行調・同主調・属調・下属調の調号が ±7 を超える場合（嬰ト短調の同主調＝嬰ト長調 など）は、異名同音の調（変イ長調）に置きかえ、画面に「異名同音」と表示します
- 短調の導音は和声的短音階にならって半音上げます。嬰ト短調・嬰ニ短調・嬰イ短調ではダブルシャープ（𝄪）になります
- 楽譜の臨時記号は、調号と違う音にだけ付け、同じ小節の中では一度付けた記号を引き継ぎます

### 曲を聴く機能の楽譜

- `music.js` の `scoreSVG()` が、音価（全音符〜16 分音符）・付点・連桁・旗・休符・拍子記号・弱起・複数段の楽譜を SVG で描きます
- 曲は主音からの度数で書いてあり（`melodies.js`）、開いた調の音に置きかえ、五線に収まりやすいオクターブを自動で選びます

### 有名な曲のデータについて

- 作曲者の没後、長い年月がたった曲だけを載せています。楽章や部分によって調が変わる曲は補足を付けています
- 「楽譜を見る」は IMSLP の作品ページへの直接リンクです。ページ名は IMSLP の API で存在を確認済みです（IMSLP の検索ページはボット対策で開けないことがあるため使っていません）。曲集に入っている曲（練習曲 Op.10 の「別れの曲」など）は曲集のページです
- 調のイメージは主観や歴史的な連想を含む目安として書いています。アプリ内の「調のイメージは本当にある？」で、平均律では調ごとの音程関係が同じであることも説明しています

## ローカルで動かす

```bash
node tools/serve.js
```

http://localhost:26838/ を開きます。スマホから Service Worker（オフライン・ホーム画面アプリ）を試すときは、`node tools/make-cert.js` で証明書を作ってから `node tools/serve.js --https` で起動してください。`tools/certs/` は秘密鍵を含むため `.gitignore` で除外しています。

### 更新するとき

ファイルを変更したら、`sw.js` の `VERSION`（例：`cy-v1` → `cy-v2`）を上げてください。インストール済みのアプリにも更新が届きます。

## データの保存

正答率・練習した日・設定は、ブラウザの localStorage（キーの先頭は `cy.`）だけに保存します。外部へは送信しません。
